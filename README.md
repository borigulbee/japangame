# 일본 놀이 미션 대전

초등학교 3학년용 일본 문화 체험 웹페이지입니다. 켄다마(けん玉)와 다루마오토시(だるま落とし) 미션을 그림으로 보고, 성공하면 체크합니다.

## 경로

| 경로 | 인원 | 체크 | 타이머 |
|---|---|---|---|
| 연습하기 | 1인 | 학생이 직접 | 없음 |
| 대전하기 | 2 · 3 · 4인 | 선생님이 확인 후 | 5분 |

주소 뒤에 `#practice` 또는 `#battle`을 붙이면 해당 화면으로 바로 이동합니다.

## 미션

- **켄다마**: 큰 접시 올리기 · 작은 접시 올리기 · 꽂기 도전(보너스)
- **다루마오토시**: 첫 블록 빼기 · 3단 클리어 · 5단 클리어 · 색깔 맞히기

## 실행

`index.html` 파일 하나로 동작합니다. 브라우저로 열거나 Netlify 같은 정적 호스팅에 올리면 됩니다. 빌드 과정은 없습니다.
